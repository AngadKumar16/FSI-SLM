Method & honest caveats

Pipeline

  • DaVis PIV frames → RawExperiment → unchanged features.extract → FeatureRecord
  • Shedding from wake v′ spectrum · POD by SVD · wake width by TKE-weighted PCA
  • Same code path as the synthetic training data — real data changed nothing downstream

What we did not fake

  • Exports are mean-subtracted — freestream U & chord c are documented rig inputs (used only for St, Re)
  • Load-cell & strain channels aren’t in a PIV-only export → written as zeros and flagged, never invented
  • Separation point from stall physics, with a provenance note
